Four things a meter reading can mean

Every household in the study falls into one of four consumption patterns. Phase 1 of the approach exists purely to sort a customer into one of these buckets.

Why utilities care

Unauthorised or unreported PV and EV installations complicate load forecasting, voltage regulation, and grid planning. This approach lets a utility scan smart‑meter data it already collects and flag which homes changed, and on what date — no satellite imagery or new hardware required.

Pipeline

Raw meter data in, a labelled change‑date out

Four stages turn a noisy 15‑minute smart‑meter feed into a scenario label and a change date.

01

Pre‑process

Clean readings, impute missing intervals from historical patterns.

02

Profile generation

Combine household load with solar output to build realistic PV / EV / PVEV / Normal consumption profiles.

03

SVC classification

An RBF‑kernel SVC (Phase 1) labels each household's sequence as PV, EV, PVEV or Normal.

04

LSTM + threshold

A personalised LSTM (Phase 2) predicts expected use; a dynamic threshold flags the change date.

Phase 1 — What changed

Support Vector Classifier (RBF)

One‑vs‑one SVC separates 4 classes using 6 binary classifiers. Hyperparameters were found with GridSearchCV: C = 11, kernel = RBF, gamma = scale. The decision function scores a new sequence against 5,780 support vectors drawn from training data.

f(x) = Σ αᵢ yᵢ K(xᵢ, x) + b

K is the RBF kernel: K(xᵢ,xⱼ) = exp(−γ‖xᵢ−xⱼ‖²). Higher γ → tighter, more sensitive decision boundaries.

Phase 2 — When it changed

Personalised LSTM + Dynamic Threshold

A 2‑layer, 32‑unit LSTM learns each customer's normal pattern and predicts expected daily consumption. The gap between prediction and reality (the "error") is compared against a threshold that adapts over time.

φ = β·t_mean + (1−β)·x̄₍last 15 days₎

Paper's tuned values: β = 0.95 (long‑ vs short‑term weighting), α = 0.1 (upper sensitivity), γ = 1.3 (historical‑mean weight). A change is confirmed once 7 consecutive days fall outside the band. Try this live in the Data Explorer tab →

Takeaway for stakeholders

A utility can run this on data it already has. PV and combined PV+EV installations are detected and dated with ~90–98% F1. EV‑only detection is strong (F1 for the scenario itself), though pinning the exact start date is the harder open problem — a natural next step highlighted in the paper's future work, alongside adding weather data to refine detection further.
